# 🛍️ Biya E-Commerce Store

Full-stack e-commerce web application built using Python and Django. Features include user authentication, shopping cart, order checkout, and PayPal payment integration with a PostgreSQL database, following Django MVT architecture.

**Features**
**User Authentication:** Secure login/signup 
**Product Management:** Search, filter by category, and sort by price.
**Shopping Cart:** 
**Checkout & Payments:** Integrated with PayPal.
**Admin Dashboard:** Role-based access to manage inventory and orders.

## 🛠️ Tech Stack
| Frontend | Backend | Database | 
| HTMl | CSS | JS | Bootstrap 5 | Django | PostgreSQL | PayPal |
